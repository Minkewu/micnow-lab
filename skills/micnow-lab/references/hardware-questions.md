# 真实硬件能力边界

MicNow Lab 是本地软件模拟器，用来试验 AI、网页与设备状态的协同流程。

- 无需连接真实 MicNow；不会枚举 USB、连接蓝牙或控制硬件。
- 不采集麦克风声音，不做真实语音识别，不向外部应用发送键盘事件。
- Speak 返回预置样例文字；页面上的连接、授权、灯态均属于模拟设备。
- 配置只保留在当前模拟设备进程中，重置或结束会话即清空。
- 本地进程间通信使用 PTY 或进程管道，不等于真实 USB 或 HID 协议。
- `target_app` 是模拟使用场景，不能用它证明某个外部客户端已经安装、登录或可以控制。

真实硬件支持需要另行完成设备发现、传输协议、权限、音频、按键、固件与断电保存测试。本仓库不包含量产硬件规格或固件发布承诺。
