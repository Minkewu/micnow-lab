## 尚未由本轮证明

- 各 Agent 是否会在全新对话中仅凭首页请求，完整执行下载、安装和启动。
- 写入技能目录后，当前宿主是否已自动刷新并发现技能。
- 豆包工作、千问等原生客户端是否允许 Agent 自动完成上传或启用；下载目录直接体验也未逐一复测。
- 可视浏览器的真实显示与交互。本轮 HTTP 请求不作为“用户已看到网页”的证据。
- Windows、Linux、远程或云端环境，以及新一轮配置修改和模拟 Speak。

因此，首页保留原生上传与手动安装入口；安装指南要求 Agent 按实际工具结果汇报“已识别安装”“文件已安装但发现未确认”或“本次体验未注册”，并在必须由用户操作时只交出当前一步。
